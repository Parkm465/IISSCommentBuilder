# Intensive Individualized Support Systems Comment Builder
## Overview
This project provides a CRUD application for the Health Technician Assistant position to efficiently document client progress notes. By leveraging previous documentation as a template, the app reduces repetitive work and speeds up comment creation. Users can add, edit, delete, and copy comments ensuring accurate and consistent documentation.

## Features
- Add new client progress comments
- Edit or delete existing comments
- Copy comments to clipboard
- Source previous comments as templates to reduce repetitive work
